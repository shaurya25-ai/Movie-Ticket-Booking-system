# Movie Ticket Booking (Java)

A console-based DSA project using a 5 x 8 seat array, a priority waitlist, HashMap booking lookup, and sorted movie listings.

## Run

```powershell
javac *.java
java Main
```

Run checks with `java MovieTicketBookingTest`. Bookings are stored in memory and reset when the program exits.
